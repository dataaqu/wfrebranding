# Service videos — drop zone

Put the original videos here (any format: .mp4, .mov, .webm). Name them by order:

| # | File name | Service |
|---|---|---|
| 1 | `1-road.mp4` | Road freight (სახმელეთო) |
| 2 | `2-sea.mp4` | Sea freight (საზღვაო) |
| 3 | `3-air.mp4` | Air freight (საჰაერო) |
| 4 | `4-rail.mp4` | Rail freight (სარკინიგზო) |
| 5 | `5-warehouse.mp4` | Warehousing |
| 6 | `6-brokerage.mp4` | Customs brokerage |

Any extension is fine (`1-road.mov` works too). Originals stay here and are not served to visitors:
they are compressed for the web (WebM + MP4 + poster) into `public/assets/services/`, which the
Services section uses in the order above.
